# Expected IIS Deployment Directory

The prebuilt IIS directory generated by `Build-IIS-Drop.ps1` will look generally like this:

```text
IIS_SITE_OUTPUT/
  Ackerman.PaymentBoard.exe
  Ackerman.PaymentBoard.dll
  Ackerman.PaymentBoard.deps.json
  Ackerman.PaymentBoard.runtimeconfig.json
  web.config
  appsettings.json
  appsettings.Production.json
  AppPages/
  wwwroot/
  Views/ or compiled view artifacts as produced by publish
  App_Data/
  logs/
  [runtime and dependency DLLs for self-contained win-x64 publish]
```

IT should deploy this output directory—not the `Source` directory.
